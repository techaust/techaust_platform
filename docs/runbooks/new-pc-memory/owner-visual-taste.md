The owner wants visuals that are unmistakably TecHaust's own: built from the brand geometry (TH mark, 45° cut, one-stroke channel, 100-unit grid) in flat ink/verdigris. They rejected generic "premium" looks (soft folds, Bloom-style gradients: "feels downloaded from anywhere with a logo placed"), 3D bevel effects, and stock "neural network" plexus. They accepted a brand-built node network (grid-snapped nodes, 0/90/45° traces, one verdigris signal path) once it was clearly visible, not ultra-subtle. Their bar is "10/10 on every aspect".

**Why:** after rounds 2–4 went richer/softer, the owner went back to the round-1 minimal brand-geometry set and asked only for refinements.

**How to apply:** for new visual work, start from the brand geometry, show a quick labelled sketch sheet early (see [[working-with-owner]]), give an honest critique of each option, and avoid generic tech/stock motifs. Related: [[techaust-rebuild-project]].
