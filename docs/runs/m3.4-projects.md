### Tests (failure paths first)
- Spoofing: `.pdf` with PNG bytes → 415 `file_type_mismatch`; HTML in `.png` refused; `.txt` with NUL or invalid UTF-8 refused; `.svg`, `.html`, `.exe` refused by the allow-list; docx bytes named `.zip` accepted; empty file → 400; `Content-Length` lying up or down → stream error, no object, no row.
- Size: 25 MiB + 1 → 413 with nothing read; missing length → 411.
- Checksum mismatch → 400 `checksum_mismatch`, nothing stored (if Miniflare doesn't verify `sha256`, say so: a staging test).
- Filenames: `../../x`, RLO (`a‮txt.exe`), control characters, `CON.txt`, 300 characters, empty; both `Content-Disposition` forms; the key format.
- Scoping: shared queries never return internal notes or unshared files; another client → none; triggers abort a note or file whose project belongs to another client, and a project whose client changes.
- RBAC loops: every write 403 for Sales; every route 403 for Accountant; signed-out 401; Sales can download.
- Codes: 20 parallel creates → 20 distinct consecutive codes; `PRJ-0999` → `PRJ-1000`.
- State machines: invalid transitions 409; terminal stays terminal; milestone invoiced/paid 409; deleting a non-pending milestone 409; reorder atomic.
- Concurrency: `expectedUpdatedAt` 409 on project, milestone and note edits. Currency different from the client's → 400.
- Delete: row and object gone; a failed R2 delete leaves no row and logs no filename.
- Regressions: non-upload routes still 413 at 16 KB and 415 for non-JSON; a cross-site upload 403.
