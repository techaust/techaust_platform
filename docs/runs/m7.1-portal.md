### A. Data (B1). New tables and new indexes only; nothing is rebuilt
**`NNNN_portal.sql` (drizzle):**
1. **`client_requests`** (POR-09, POR-11):
   - Columns: `id` (uuidv7); `client_id` → clients **NULL** (M7.4 amendment, below); `contact_id` → contacts NULL; `lead_id` → leads NULL; `lead_ref` TEXT ≤ 64 NULL (the lead's id as plain text, **no foreign key**, no personal data; set with `lead_id` and kept when the lead is deleted); `requester_email` TEXT ≤ 254 NULL; `kind`; `details` TEXT ≤ 1000 NULL; `status` (`open`, `closed`); `outcome` (`done`, `declined`) NULL; `closed_by` → staff_users NULL; `closed_at`; `close_note` ≤ 500; `created_at`; `updated_at`.
   - `kind` is one of `contact_change`, `data_access`, `data_correction`, `data_erasure`, `grievance` (L8).
   - Indexes: `(client_id, created_at, id)`; `client_requests_status (status, created_at, id)`; UNIQUE partial `(contact_id, kind) WHERE status = 'open'`; `(contact_id, created_at)` for the daily cap.
   - **M7.4 amendment (lead, 2026-11-01):** rights requests also come from enquirers (leads) and people not in our records, and SQLite can't make a column nullable later without a rebuild (forbidden for a referenced table). So `client_id` is NULL-able, with `lead_id` and `requester_email`, and a table CHECK that at least one of `client_id`, `lead_ref`, `requester_email` is set (a new table: no rebuild; `lead_ref`, not `lead_id`, so the unlink below can't break it). Every portal insert sets `client_id` from the session; portal reads keep `client_id = ?1`, so NULL rows never reach the portal. The kind trigger lists the five kinds above; M7.4 re-creates it with `consent_withdrawal` and `nomination`.
   - M7.4 adds its clock by ADD COLUMN.
2. **`payment_notices`** ("I've paid", ADM-PAY-05):
   - Columns: `id`; `client_id` → clients; `document_id` → documents; `contact_id` → contacts NULL; `via` (`portal`, `link`); `amount_minor` CHECK > 0; `currency`; `paid_on` (ISO date); `reference` (1–64 characters); `reference_norm` (M6.1's normaliser); `note` ≤ 300 NULL; `status` (`open`, `recorded`, `dismissed`); `payment_id` → payments NULL; `closed_by` → staff_users NULL; `closed_at`; `created_at`.

3. **New partial indexes on existing tables** (CREATE INDEX only):
   - `notes_shared_project (project_id, created_at, id) WHERE visibility = 'shared'`;
   - `files_shared_project (project_id, created_at, id) WHERE shared = 1`;
