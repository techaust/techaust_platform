### Rules (each one is a test; all VERIFY WITH CA/LEGAL)
1. **Reported rows:** only the four kinds, `voided = false`, `issueDate` in the period. Voided documents appear only in Table 13 as "Cancelled". Any other kind → error `kind_not_reportable`; rows are never silently skipped; a bad row fails the whole result with `path: [row.id]`.
2. **Periods:** month = 1st to last day; quarter Q1 = Apr–Jun of `fyStartYear` … Q4 = Jan–Mar of `fyStartYear + 1` (QRMP). IST calendar dates.
3. **Invoice section (`classifyInvoice`):** `export_lut`/`export_igst` → **exp** (`WOPAY` / `WPAY`; includes an INR export, Q8). Else registered → **b2b** (GSTIN required `gstin_missing`, valid by `validateGstin` else `gstin_invalid`). Else unregistered ∧ `inter` ∧ `totalInrMinor > threshold` (strictly more; exactly ₹1,00,000.00 is b2cs) → **b2cl**. Else **b2cs**. `DEFAULT_B2CL_THRESHOLD_INR_MINOR = 1_00_000_00`; a negative or non-integer threshold → `threshold_invalid`.
4. **Note section (`classifyNote`, by the parent's section, same threshold):** parent b2b → **cdnr**; b2cl → **cdnur** `UR Type = B2CL`; exp → **cdnur** `EXPWOP`/`EXPWP`; b2cs → netted into **b2cs** (CN negative, DN positive). No `noteOf` → `parent_missing`.
5. **Row shape:** b2b, b2cl, exp, cdnr, cdnur: one row per (document, `rateBp`), document value repeated (INR). b2cs: one row per (POS, rate), signed sums, sorted by POS then rate; a negative net is kept and warns `b2cs_negative_net`.
6. **HSN:** `hsnB2b` = b2b invoices + cdnr notes; `hsnB2c` = everything else (b2cl, b2cs, exp, cdnur). Aggregate by (SAC, rate); CN negative, DN positive; Total Value = taxable + IGST + CGST + SGST. Null SAC → `sac_missing`; a SAC missing from `sacDescriptions` → blank description + warning `hsn_description_missing`.
7. **Row checks:** amounts safe integers ≥ 0 (`amount_invalid`; sign from the kind, never the input); `rates` not empty (`rates_empty`); `rateBp` integer 0–10,000 (`rate_invalid`); Σ(taxable + heads) + `roundOffInrMinor` = `totalInrMinor` (`totals_mismatch`); POS known (`pos_invalid`); export ⇔ POS 96 (`export_pos_mismatch`); number 1–16 characters (`number_invalid`); no duplicate id or (kind, number) (`duplicate_row`); valid date (`date_invalid`). All maths in bigint with a checked `num()` back.
8. **Totals (`Gstr1Totals`):** signed sums of taxable, IGST, CGST, SGST and value per section and overall; overall = Σ of the reported register rows signed by kind; HSN b2b + HSN b2c = the same (the ADM-REP-04 "totals match" check).
9. **Table 13 (`docsRows`):** one row per input in `SERIES` key order. `NATURE_OF_DOCUMENT`: `invoice` and `export` → "Invoices for outward supply" (two rows, 08-A :198); `creditNote` → "Credit Note"; `debitNote` → "Debit Note"; `receiptVoucher` → "Receipt voucher"; `refundVoucher` → "Refund voucher". A series with `gst: false` → `series_not_gst`; integers with 0 ≤ cancelled ≤ total and non-empty `from`/`to` else `docs_counts_invalid`. The net figure is left to the Offline Tool (UNVERIFIED). Table 13 is by interface only: never import or re-implement `documentsIssuedSummary`.
10. **`registerRatesOf(computed)`:** group `computed.lines` by (`sac`, `effectiveRateBp`); INR documents use the line values, USD documents `line.inr` (missing → `fx_missing`). Sums must equal `computed.inr ?? computed` for taxable and each head. UNVERIFIED that the engine guarantees Σ `line.inr` = `ComputedInr`: if a property run finds a mismatch, **stop and report**; don't patch around it.
11. **CSV (`writeCsv`, RFC 4180):** `,` separator; **every record ends in CRLF**, header included; fields holding `"`, `,`, CR or LF are quoted with `"` doubled, inner line breaks kept; UTF-8; BOM only with `opts.bom` (v1 off, UNVERIFIED). **Typed cells:** `text` cells go through `defuse` (a leading `=`, `+`, `-`, `@`, tab or CR gets a `'` prefix: the set of `apps/admin/src/lib/audit.ts:286`); numeric cells only from `cell.amount(minor)` (`-500.00`), `cell.rate(bp)` (1800 → `18`, 1250 → `12.5`, 25 → `0.25`, 0 → `0`), `cell.count(n)`, and are **never defused**; `cell.date(d)` → `dd-Mmm-yyyy` (`05-Oct-2026`, UNVERIFIED); `cell.blank()`. No string-to-number path.
12. **Layouts:** `GSTR1_LAYOUTS["gstr1-csv-v1"]`: per section the file stem and ordered `{header, cell(row)}`, `Object.freeze` + `as const`. A version is never edited; a change is `-v2`; a snapshot test pins every version's headers. **Column set v1 (UNVERIFIED, from memory of the Offline Tool template):**
    - **b2b:** GSTIN/UIN of Recipient · Receiver Name · Invoice Number · Invoice date · Invoice Value · Place Of Supply · Reverse Charge (`Y`/`N`) · Applicable % of Tax Rate (blank) · Invoice Type (`Regular B2B`) · E-Commerce GSTIN (blank) · Rate · Taxable Value · Cess Amount (blank)
    - **b2cl:** Invoice Number · Invoice date · Invoice Value · Place Of Supply · Applicable % of Tax Rate · Rate · Taxable Value · Cess Amount · E-Commerce GSTIN
    - **b2cs:** Type (`OE`) · Place Of Supply · Applicable % of Tax Rate · Rate · Taxable Value · Cess Amount · E-Commerce GSTIN
    - **exp:** Export Type · Invoice Number · Invoice date · Invoice Value · Port Code · Shipping Bill Number · Shipping Bill Date (last three blank) · Rate · Taxable Value · Cess Amount
    - **cdnr:** GSTIN/UIN of Recipient · Receiver Name · Note Number · Note Date · Note Type (`C`/`D`) · Place Of Supply · Reverse Charge · Note Supply Type (`Regular B2B`) · Note Value · Applicable % of Tax Rate · Rate · Taxable Value · Cess Amount
    - **cdnur:** UR Type · Note Number · Note Date · Note Type · Place Of Supply (blank for exports) · Note Value · Applicable % of Tax Rate · Rate · Taxable Value · Cess Amount
    - **hsn_b2b / hsn_b2c:** HSN · Description · UQC (`NA`) · Total Quantity (`0`) · Total Value · Rate · Taxable Value · Integrated Tax Amount · Central Tax Amount · State/UT Tax Amount · Cess Amount
    - **docs:** Nature of Document · Sr. No. From · Sr. No. To · Total Number · Cancelled
    - Place of supply written `19-West Bengal` from the layout's own label table over `STATE_CODES` (labels for legacy codes 25 and 28 UNVERIFIED). Exports' Rate = the effective rate (0 under LUT, UNVERIFIED).
    - **`edf-v1`** (our working list for the AD bank, not the bank's form; UNVERIFIED): Invoice number · Invoice date · Client name · Client address · Country (ISO code) · Currency · Invoice amount · Exchange rate (micros as a 6-decimal string) · INR value · SAC · Service description · Purpose code · Amount realised · FEMA realisation due · EDF due.
    - **`realisation-v1`:** Invoice number · Invoice date · Client · Currency · Outstanding · FEMA due · GST due · Stage.
13. **Realisation** (FEMA 2026 as amended 22 Sep 2026; Rule 96A(1)(b)): rules `{ femaMonthsForeign: 9, femaMonthsInr: 12, gstMonths: 12, gstExtraDays: 15, approachingDays: 30, rulesFrom: 2026-10-01 }`; `realisationRulesOf(settings.tax.realisation)` maps `warnMonths` → `femaMonthsForeign`, `escalateMonths` → `gstMonths`, `escalateExtraDays` → `gstExtraDays` (`femaMonthsInr` default until M5.5b). `femaDue = addMonthsClamped(invoiceDate, inInr ? femaMonthsInr : femaMonthsForeign)` unless `extension.femaDue` is given; `gstDue = addDays(max(addMonthsClamped(invoiceDate, gstMonths), femaDue), gstExtraDays)`. Both are the last allowed day; overdue when `today > due`. `addMonthsClamped` clamps to month end (31 May + 9 → 28/29 Feb; 29 Feb + 12 → 28 Feb; VERIFY). Stage in order: outstanding ≤ 0 → `realised`; `today > gstDue` → `gst_overdue`; `today ≥ gstDue − approachingDays` → `gst_approaching`; `today > femaDue` → `fema_overdue`; `today ≥ femaDue − approachingDays` → `fema_approaching`; else `ok`. Before `rulesFrom` → warning `before_fema_2026` (docs/08 U-2). Zero or non-integer months → `rules_invalid`.
14. **EDF:** `edfMonth(year, month)` → `{from, to, due = lastDayOfMonth + 30 days}`; `edfRows(register, year, month)` = every non-voided `export_invoice` dated in the month, all payment rails (Q16), sorted by date then number; USD without `fxRateMicros` → `fx_missing`. Export credit notes not included (VERIFY).
15. **Implementation:** deterministic sorted output (date then number; POS then rate; SAC then rate). No floats: the scanner also bans plain `/` and `Math.floor`; for month maths use `%` or `Math.trunc(a / b)` on plain operands (e.g. `const t = m - 1 + n; Math.trunc(t / 12)`).
